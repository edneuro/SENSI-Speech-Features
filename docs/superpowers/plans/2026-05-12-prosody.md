# Acoustic Prosody Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add word-level (10 cols) and document-level (16 cols) acoustic prosody features to SensiExtractor using Praat-Parselmouth.

**Architecture:** Layered. `extractors/audio_features.py` does a single Parselmouth pass per stimulus and returns a `Contours` dataclass (pitch_hz, intensity_db, hnr_db, speaker_median, times). `extractors/prosody.py` consumes those contours plus the MFA-aligned word DataFrame to produce pure-pandas aggregations — `add_word_prosody` for the word CSV, `compute_doc_prosody` for the doc summary. `main.py:run()` runs `audio_features.extract` then `add_word_prosody` after MFA alignment; `run_doc_level_batch` reuses the cached `Contours` object via `args._contours` so `build_doc_summary` does not re-invoke Parselmouth.

**Tech Stack:** Python 3.10+, `praat-parselmouth>=0.4`, `pyphen>=0.14`, pandas, numpy, PySide6 (GUI), pytest.

**Spec:** `docs/superpowers/specs/2026-05-12-prosody-design.md` — read first.

**Commit cadence:** One commit per Task (not per step). Each task is a self-contained unit of work that leaves the codebase green.

```python
"""Parselmouth (Praat) wrapper — one acoustic-analysis pass per stimulus.

extract(audio_path, ...) -> Contours dataclass holding:
    pitch_hz: 1-D np.ndarray, NaN at unvoiced frames
    intensity_db: 1-D np.ndarray, dB SPL
    times: 1-D np.ndarray, frame timestamps (seconds, aligned to pitch frames)
    frame_rate_hz: int (default 100, i.e. 10 ms time step)
    speaker_median_pitch_hz: float — semitone reference
    hnr_db: float — mean Harmonics-to-Noise Ratio over voiced frames

Raises ProsodyUnavailable if parselmouth isn't importable.
"""
from __future__ import annotations

from dataclasses import dataclass
import numpy as np

try:
    import parselmouth  # type: ignore
    _PARSELMOUTH_OK = True
except ImportError:
    _PARSELMOUTH_OK = False


class ProsodyUnavailable(RuntimeError):
    """Raised when parselmouth is not importable; callers emit NaN cols."""


@dataclass(frozen=True)
class Contours:
    pitch_hz: np.ndarray
    intensity_db: np.ndarray
    times: np.ndarray
    frame_rate_hz: int
    speaker_median_pitch_hz: float
    hnr_db: float


def extract(audio_path: str, *,
            pitch_floor_hz: float = 75.0,
            pitch_ceiling_hz: float = 500.0,
            time_step_s: float = 0.01) -> Contours:
    """Single Parselmouth pass; returns Contours."""
    if not _PARSELMOUTH_OK:
        raise ProsodyUnavailable(
            "praat-parselmouth is not installed. Run: pip install praat-parselmouth")

    snd = parselmouth.Sound(audio_path)

    pitch = snd.to_pitch_ac(
        time_step=time_step_s,
        pitch_floor=pitch_floor_hz,
        pitch_ceiling=pitch_ceiling_hz,
    )
    pitch_values = pitch.selected_array['frequency'].astype(float)
    # Unvoiced frames come back as 0.0 in Praat; convert to NaN.
    pitch_values[pitch_values == 0.0] = np.nan
    pitch_times = pitch.xs().astype(float)

    intensity = snd.to_intensity(
        minimum_pitch=pitch_floor_hz,
        time_step=time_step_s,
    )
    int_values = intensity.values.flatten().astype(float)
    int_times = intensity.xs().astype(float)

    # Resample intensity onto pitch's time grid (handles minor edge offsets).
    intensity_db = np.interp(pitch_times, int_times, int_values,
                              left=np.nan, right=np.nan)

    # Speaker median pitch (used as semitone reference).
    voiced = pitch_values[~np.isnan(pitch_values)]
    speaker_median = float(np.median(voiced)) if voiced.size else float('nan')

    # HNR (mean over voiced frames).
    try:
        harmonicity = snd.to_harmonicity_cc(
            time_step=time_step_s,
            minimum_pitch=pitch_floor_hz,
        )
        hnr_vals = harmonicity.values.flatten()
        hnr_vals = hnr_vals[np.isfinite(hnr_vals)]
        hnr_mean = float(np.mean(hnr_vals)) if hnr_vals.size else float('nan')
    except Exception:
        hnr_mean = float('nan')

    return Contours(
        pitch_hz=pitch_values,
        intensity_db=intensity_db,
        times=pitch_times,
        frame_rate_hz=int(round(1.0 / time_step_s)),
        speaker_median_pitch_hz=speaker_median,
        hnr_db=hnr_mean,
    )
```

"""Word- and document-level prosody aggregators.

Consumes a Contours object from extractors.audio_features and an MFA-aligned
word DataFrame. Pure pandas/numpy; no Parselmouth calls happen here.

See docs/superpowers/specs/2026-05-12-prosody-design.md §5–7 for the column
definitions and edge-case rules.
"""
from __future__ import annotations

import numpy as np
import pandas as pd

from extractors.audio_features import Contours


_WORD_PROSODY_COLS = (
    "Pitch_Mean", "Pitch_Min", "Pitch_Max", "Pitch_Std",
    "Volume_Mean", "Volume_Min", "Volume_Max", "Volume_Std",
)


def _semitones_from_hz(hz_array: np.ndarray, ref_hz: float) -> np.ndarray:
    """Convert Hz array to semitones relative to ref_hz. NaN-safe."""
    if not np.isfinite(ref_hz) or ref_hz <= 0:
        return np.full_like(hz_array, np.nan)
    return 12.0 * np.log2(hz_array / ref_hz)


def _slice(times: np.ndarray, values: np.ndarray,
           onset: float, end: float) -> np.ndarray:
    """Return values whose times fall in [onset, end)."""
    if not np.isfinite(onset) or not np.isfinite(end):
        return np.array([], dtype=float)
    mask = (times >= onset) & (times < end)
    return values[mask]


def _agg(values: np.ndarray) -> tuple[float, float, float, float]:
    """(mean, p5, p95, std) over non-NaN entries; all NaN if no valid frames."""
    finite = values[~np.isnan(values)]
    if finite.size == 0:
        return (np.nan, np.nan, np.nan, np.nan)
    if finite.size == 1:
        v = float(finite[0])
        return (v, v, v, 0.0)
    return (
        float(np.mean(finite)),
        float(np.percentile(finite, 5)),
        float(np.percentile(finite, 95)),
        float(np.std(finite)),
    )


def add_word_prosody(df: pd.DataFrame, contours: Contours,
                     *, pitch_units: str = "semitones") -> pd.DataFrame:
    """Append 10 prosody columns to df. df is not modified in place."""
    df = df.copy()
    pitch = contours.pitch_hz
    if pitch_units == "semitones":
        pitch = _semitones_from_hz(pitch, contours.speaker_median_pitch_hz)
    elif pitch_units != "hz":
        raise ValueError(f"pitch_units must be 'hz' or 'semitones', got {pitch_units!r}")

    onsets = df["Onset"].to_numpy() if "Onset" in df.columns else np.full(len(df), np.nan)
    ends = df["End"].to_numpy() if "End" in df.columns else np.full(len(df), np.nan)

    pitch_aggs, vol_aggs = [], []
    for on, en in zip(onsets, ends):
        if not (np.isfinite(on) and np.isfinite(en)):
            pitch_aggs.append((np.nan,) * 4)
            vol_aggs.append((np.nan,) * 4)
            continue
        pitch_aggs.append(_agg(_slice(contours.times, pitch, on, en)))
        vol_aggs.append(_agg(_slice(contours.times, contours.intensity_db, on, en)))

    p_mean, p_min, p_max, p_std = zip(*pitch_aggs) if pitch_aggs else ([], [], [], [])
    v_mean, v_min, v_max, v_std = zip(*vol_aggs) if vol_aggs else ([], [], [], [])

    df["Pitch_Mean"]  = list(p_mean)
    df["Pitch_Min"]   = list(p_min)
    df["Pitch_Max"]   = list(p_max)
    df["Pitch_Std"]   = list(p_std)
    df["Volume_Mean"] = list(v_mean)
    df["Volume_Min"]  = list(v_min)
    df["Volume_Max"]  = list(v_max)
    df["Volume_Std"]  = list(v_std)

    # Word-to-word deltas (NaN for first word).
    df["Pitch_Delta"] = df["Pitch_Mean"].diff()
    df["Volume_Delta"] = df["Volume_Mean"].diff()
    return df
```

def _count_syllables(token: str) -> int:
    """Surface-form syllable count via pyphen. Returns 1 on lookup failure."""
    try:
        import pyphen  # type: ignore
    except ImportError:
        return -1  # sentinel — caller emits NaN
    if not hasattr(_count_syllables, "_dic"):
        _count_syllables._dic = pyphen.Pyphen(lang="en_US")
    if not token:
        return 0
    return _count_syllables._dic.inserted(token).count("-") + 1


def compute_doc_prosody(df: pd.DataFrame, contours: Contours, *,
                        text: str, pause_threshold_s: float = 0.25,
                        pitch_units: str = "semitones") -> dict[str, float]:
    """Return 16 doc-level prosody columns as a flat dict."""
    # Whole-stimulus pitch/volume aggregates (apply unit conversion).
    pitch_arr = contours.pitch_hz
    if pitch_units == "semitones":
        pitch_arr = _semitones_from_hz(pitch_arr, contours.speaker_median_pitch_hz)
    p_mean, p_min, p_max, p_std = _agg(pitch_arr)
    v_mean, v_min, v_max, v_std = _agg(contours.intensity_db)

    # Mean absolute deltas from per-word columns.
    pitch_delta_mean = float(df["Pitch_Delta"].abs().mean()) if "Pitch_Delta" in df else float("nan")
    volume_delta_mean = float(df["Volume_Delta"].abs().mean()) if "Volume_Delta" in df else float("nan")

    # Pause statistics over MFA word rows.
    aligned = df.dropna(subset=["Onset", "End"]).sort_values("Onset").reset_index(drop=True)
    pauses = []
    if len(aligned) >= 2:
        gaps = aligned["Onset"].to_numpy()[1:] - aligned["End"].to_numpy()[:-1]
        pauses = gaps[gaps > pause_threshold_s].tolist()
    pause_count = len(pauses)
    pause_total = float(sum(pauses))
    pause_mean = float(np.mean(pauses)) if pauses else 0.0
    if len(aligned) >= 1:
        stim_duration = float(aligned["End"].iloc[-1] - aligned["Onset"].iloc[0])
    else:
        stim_duration = float("nan")
    pause_pct = (pause_total / stim_duration) if stim_duration and stim_duration > 0 else float("nan")

    # Articulation rate: syllables / spoken time (excludes pauses by definition).
    syllable_total = 0
    spoken_time = 0.0
    pyphen_ok = True
    for _, row in aligned.iterrows():
        if row.get("upos") == "PUNCT":
            continue
        syl = _count_syllables(str(row["token"]))
        if syl < 0:
            pyphen_ok = False
            break
        syllable_total += syl
        spoken_time += float(row["End"]) - float(row["Onset"])
    if not pyphen_ok or spoken_time <= 0:
        articulation = float("nan")
    else:
        articulation = syllable_total / spoken_time

    return {
        "doc_pitch_mean": p_mean,
        "doc_pitch_min": p_min,
        "doc_pitch_max": p_max,
        "doc_pitch_std": p_std,
        "doc_volume_mean": v_mean,
        "doc_volume_min": v_min,
        "doc_volume_max": v_max,
        "doc_volume_std": v_std,
        "doc_pitch_delta_mean": pitch_delta_mean,
        "doc_volume_delta_mean": volume_delta_mean,
        "doc_hnr": float(contours.hnr_db),
        "doc_articulation_rate": articulation,
        "doc_pause_count": pause_count,
        "doc_pause_mean_duration": pause_mean,
        "doc_pause_total_duration": pause_total,
        "doc_pause_pct_silence": pause_pct,
    }
```

```markdown
## Acoustic Prosody (word-level, 10 columns)

Extracted via Praat-Parselmouth from the audio file, segmented by MFA word boundaries.

| Column | Definition | Unit |
|---|---|---|
| `Pitch_Mean` | Mean F0 over voiced frames in the word | Hz or semitones (see Pitch units below) |
| `Pitch_Min` / `Pitch_Max` | 5th / 95th percentile (robust to tracker errors) | same |
| `Pitch_Std` | Std over voiced frames | same |
| `Volume_Mean` / `Volume_Min` / `Volume_Max` / `Volume_Std` | Same aggregates over intensity (dB SPL) | dB |
| `Pitch_Delta` / `Volume_Delta` | Word-to-word change (`X[i] - X[i-1]`); NaN for first word | same |

**Pitch units** — `--pitch-units` flag, GUI combobox, or `prefs.prosody.pitch_units`. Choices: `hz` (raw) or `semitones` (relative to per-stimulus voiced-pitch median). Unit recorded in run manifest.

**Pitch search range** — `--pitch-floor` / `--pitch-ceiling` (defaults 75 / 500 Hz). Adjust for high-pitched (children) or low-pitched (male bass) voices to avoid octave errors.

**Unvoiced words** — pitch columns NaN; volume columns still valid.

**No alignment** — all 10 columns NaN (prosody depends on MFA Onset/End).

## Acoustic Prosody (document-level, 16 columns)

Emitted into `documents_summary_*.csv`. See spec §7 for exact definitions.

- `doc_pitch_*` / `doc_volume_*` — same aggregates as word level but over the whole stimulus.
- `doc_pitch_delta_mean` / `doc_volume_delta_mean` — mean of |Pitch_Delta| / |Volume_Delta| across words.
- `doc_hnr` — Harmonics-to-Noise Ratio (Praat `to_harmonicity_cc`, mean over voiced frames). Boersma (1993).
- `doc_articulation_rate` — total syllables (via `pyphen` on each word's surface form) / total spoken time (excluding pauses), syllables/sec.
- `doc_pause_*` — count, mean, total, % silence. Pause = inter-word gap > `--pause-threshold` (default 250 ms).

**Dependencies:** `praat-parselmouth>=0.4`, `pyphen>=0.14`. Install via `pip install -r requirements.txt`.
```
