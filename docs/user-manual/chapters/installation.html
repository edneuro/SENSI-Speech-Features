3Installation

Three steps — install Miniconda, run the setup script once, launch the app.

3.1Step 1 — Install Miniconda

Download the installer for your system from anaconda.com/docs/getting-started/installation.

Run the .exe with the default options. Use the Anaconda Prompt (in your Start menu) for every command below — it already has conda set up.

Run the Apple-Silicon .pkg (or .sh) installer, then set conda up for your shell and open a new Terminal window:

conda init zsh          # zsh is the macOS default

Run the .sh installer, then set conda up for your shell and open a new terminal:

conda init bash         # or zsh / fish
"Run 'conda init' before 'conda activate'"? The init step hasn't been loaded. Run conda init <your-shell>, open a new terminal, and try again.

3.2Step 2 — Get the project and run the setup script

Download the project from github.com/edneuro/SENSI-Speech-Features (green Code button → Download ZIP, or git clone). Then, from inside the project folder:

In the Anaconda Prompt:

cd path\to\SENSI-Speech-Features
setup.bat

cd path/to/SENSI-Speech-Features
bash setup.sh

The script does five things, and prints each as it goes:

  1. Installs conda-lock into your base conda — the tool that installs exact, pinned versions.
  2. Creates ./env inside the project folder from conda-lock.yml, a lock file that pins every package for your platform. Everyone gets the same versions.
  3. Downloads the forced-aligner models into data/mfa_data/.
  4. Downloads the spaCy English model into the environment.
  5. Creates a double-click launcher for your machine (with the app icon).

It takes a while (the environment is about 6 GB). You only do it once.

3.3Step 3 — Launch

Double-click the SENSI-SpeechFeatures launcher the setup created in the project folder:

System Launcher Notes
Windows SENSI-SpeechFeatures shortcut (runs runGUI.bat) a console window opens next to the app with live progress — that's intentional
macOS SENSI-SpeechFeatures.app no Terminal window; the log goes to ~/Library/Logs/SENSI-SpeechFeatures.log. For live logs, double-click runGUI.command instead
Linux SENSI-SpeechFeatures desktop entry (runs runGUI.sh)

Or from a terminal in the project folder:

conda activate ./env
python gui.py

3.4Updating to a newer version

From the project folder, git pull (or download the new ZIP over the old folder), then start the app as usual. If the dependencies changed, run the setup script again — it rebuilds env/ from the new lock file.
