1Introduction

SensiExtractor turns a spoken stimulus — an audio recording and its transcript — into time-aligned tables of linguistic and acoustic features, ready to relate to EEG.

1.1What SensiExtractor is for

Naturalistic EEG studies play people real speech — stories, lectures, conversations — and ask how the brain follows it. To analyse that, every stimulus first has to be described in numbers: when each word was spoken, how frequent or predictable it is, what part of speech it is, how high and loud the voice was, how the sound energy moved over time. SensiExtractor is the standardized tool of the SENSI naturalistic-EEG pipeline (ISC Wu Tsai dataset) that produces those descriptions the same way for every stimulus, so analyses across studies use the same definitions.

You give it a folder of transcripts (.txt) and, usually, the matching recordings (.wav, paired by file name). It writes, for each stimulus, CSV tables and MATLAB .mat files, plus one summary table for the whole set. Every time-based value is on the recording's own clock, so it lines up with your EEG events.

  1. The transcript is cleaned (numbers spelled out, spacing normalized) and parsed by spaCy into tokens, sentences and grammatical annotations.
  2. If there is a recording, the Montreal Forced Aligner finds when each word — and each syllable and sound inside it — was spoken. This runs once per stimulus and is saved, so later runs reuse it.
  3. Each feature you switched on is computed from those pieces and written into the table for its level. Features you leave off are not computed and leave no columns behind.

1.3The five output levels

Level One row per Typical use Chapter
Word word (and punctuation token) word-locked ERPs, TRF predictors at word onsets Word level
Sub-word syllable, phoneme syllable / phoneme-rate tracking, cohort models Sub-word level
Sentence sentence sentence-level prosody, sentence embeddings Sentence level
Document stimulus comparing or balancing stimuli Document level
Acoustic time step (e.g. 128 Hz) continuous TRF predictors from the audio alone Acoustic level

1.4How to use this manual

  • New to the tool: read Requirements, Installation and Using the app, in that order.
  • Looking up a feature or a column name: type it in the search box (top left, or press /), or open Features.
  • Running large batches on Stanford's cluster: Running on Sherlock.
  • Looking for a file in your output folder: Outputs reference.
Where the examples come from. Every figure, table and number in this manual is real SensiExtractor output, computed when the manual was built. The recordings are from the LJ Speech dataset (public domain, a single speaker reading non-fiction); two short invented sentences, run without audio, show the predictability features. No study stimuli are included.

The text of each feature page is the same text the app shows when you click a feature's ⓘ icon, so the manual and the app always say the same thing.
