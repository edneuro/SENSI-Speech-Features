6.1.3Sentence text

The verbatim text of the sentence containing each word, including punctuation and original whitespace.

App: Word-level features → StructuralOutput: word/<stim>_features.csvLibraries: spaCy

6.1.3.1What it is

The verbatim text of the sentence containing each word, including punctuation and original whitespace. Every word row in the same sentence_id carries the same sentence string — redundant by design, so downstream consumers can join sentence-level context without a separate lookup.

6.1.3.2See it

Example text (invented, run without audio): structure.txt: “The dog barked. Then it slept. Morning came.”
tokenThedogbarked.
sentence_id1111
sentenceThe dog barked.The dog barked.The dog barked.The dog barked.
Read from word/structure_features.csv, written by SENSI SpeechFeatures on the example shown here. Nothing on this figure is typed in.

6.1.3.4MATLAB

% Load the word-level table (one row per word)
T = readtable('word/structure_features.csv', 'TextType', 'string');
T.Properties.VariableNames             % every column in the file
head(T(:, {'sentence_id', 'token', 'sentence'}), 10)                % this feature's columns (first rows)
Run from the output folder. Variable and column names were checked against the real files when this manual was built; the code itself was not run in MATLAB.

6.1.3.5Usage

  • Display context for a word during manual inspection of the word-level CSV.
  • Reconstruct sentences for sentence-level analysis without needing the sentence-level sidecar.
  • Combine with start / end to reproduce the surface token from its sentence: sentence[start-1:end].
