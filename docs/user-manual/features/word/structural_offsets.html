6.1.2Structural character offsets

1-indexed, inclusive character offsets of each token within the sentence string (the sentence column).

App: Word-level features → StructuralOutput: word/<stim>_features.csvLibraries: spaCy

6.1.2.1What it is

1-indexed, inclusive character offsets of each token within the sentence string (the sentence column).

Column Meaning
start Position of the token's first character within its sentence. First character of the sentence is 1.
end Position of the token's last character within its sentence. Inclusive.

⚠️ Easy to confuse with Onset / End (capitalized), which are the acoustic word boundaries in seconds from sensi/extractors/aligner.py. These character offsets are lowercase start / end and are in characters within the sentence, not seconds.

6.1.2.2See it

Example LJ002-0321 (LJ Speech, public domain): “Others who arrived just after the time of distribution were often 48 hours without food. The latter might also be six days without meat.”

6.1.2.4MATLAB

% Load the word-level table (one row per word)
T = readtable('word/LJ002-0321_features.csv', 'TextType', 'string');
T.Properties.VariableNames             % every column in the file
head(T(:, {'sentence_id', 'token', 'start', 'end'}), 10)                % this feature's columns (first rows)
Run from the output folder. Variable and column names were checked against the real files when this manual was built; the code itself was not run in MATLAB.

6.1.2.5Usage

  • Slice the sentence string with sentence[start-1:end] to get the token's surface form (matching the token column).
  • Useful for joining downstream annotations that are also indexed in sentence-relative character coordinates.

6.1.2.6In the code

Open in GitHub
  • sensi/extractors/text_parser.py → parse()

Source: sensi/extractors/text_parser.py:parse.

Computed as token.idx - sent.start_char + 1 and char_start + len(token.text) - 1 during the spaCy sentence walk. The +1 converts spaCy's native 0-indexed offsets into the 1-indexed inclusive convention used throughout the SensiExtractor outputs.
