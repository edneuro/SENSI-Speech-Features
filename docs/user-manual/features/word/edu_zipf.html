6.1.9Educator's Word Frequency Guide (EWFG) grade-band frequencies

Per-word Zipf-scale frequencies derived from the Educator's Word Frequency Guide (Zeno 1995), a corpus of texts that American schoolchildren actually encounter, bucketed by grade band.

App: Word-level features → FrequencyLibraries: pyarrowNot computed in this manualStatus: unavailable

6.1.9.1What it is

Per-word Zipf-scale frequencies derived from the Educator's Word Frequency Guide (Zeno 1995), a corpus of texts that American schoolchildren actually encounter, bucketed by grade band:

Column Grade band
Edu_Zipf_K2 Kindergarten through 2nd grade
Edu_Zipf_3to5 3rd–5th grade
Edu_Zipf_6to8 6th–8th grade
Edu_Zipf_9to12 9th–12th grade
Edu_Zipf_Overall Aggregated across all bands

Each column uses the same Zipf scale as Zipf_Freq, just computed against a different reference corpus. Missing-from-lookup rows are NaN (PUNCT rows also NaN).

6.1.9.2See it

◇ Not computed in this manual

The Educator's Word Frequency Guide exists only in print, so there is no lookup table; these columns are never written (the planner leaves them out unless you supply data/dictionaries/edu_zipf.parquet).

Columns this feature writes when it runs: Edu_Zipf_K2, Edu_Zipf_3to5, Edu_Zipf_6to8, Edu_Zipf_9to12, Edu_Zipf_Overall

6.1.9.3In your output

When it runs, this feature writes these columns: Edu_Zipf_K2, Edu_Zipf_3to5, Edu_Zipf_6to8, Edu_Zipf_9to12, Edu_Zipf_Overall.

6.1.9.4MATLAB

Nothing to load: this feature is not written in this manual's example outputs.

6.1.9.5Data acquisition

No digital source exists. The Educator's Word Frequency Guide (Zeno 1995) was published as a print reference and, as far as we have been able to determine, has never been released in machine-readable form. SensiExtractor therefore ships no data/dictionaries/edu_zipf.parquet, and without it the planner leaves these columns out of every run.

To enable these columns in future, a data/dictionaries/edu_zipf.parquet would need to be built — indexed by word, with columns edu_zipf_k2, edu_zipf_3to5, edu_zipf_6to8, edu_zipf_9to12, edu_zipf_overall — from a digitized copy of the guide (book reference: https://books.google.com/books/about/The_Educator_s_Word_Frequency_Guide.html?id=jsJ1QgAACAAJ). Once that file is in place, a headless run.py with the freq_ewfg_* (and, for the document means, doc_agg_edu_zipf) toggles on in config/features.yaml produces the columns; the app's toggles stay disabled until the GUI is changed to match.

6.1.9.6In the code

Open in GitHub
  • sensi/extractors/educator_freq.py → add_edu_freq()
  • sensi/gui/planner/registry.py

Source: sensi/extractors/educator_freq.py:add_edu_freq.

What the code does:

  1. Loads a parquet lookup from data/dictionaries/edu_zipf.parquet (or a user-supplied path), indexed by word, with columns edu_zipf_k2, edu_zipf_3to5, edu_zipf_6to8, edu_zipf_9to12, edu_zipf_overall.
  2. Lookups are keyed on lemma.lower(); upos == "PUNCT" rows are sentinel-keyed to "__missing__" so they always miss and surface as NaN.
  3. Uses pandas.DataFrame.reindex for a vectorized lookup — much faster than a per-row apply for long transcripts.
  4. The planner runs it only when the parquet exists. The word-level EWFG cluster and the document mean_edu_zipf_* cluster both declare requires_dictionary="edu_zipf.parquet" (sensi/gui/planner/registry.py), so without data/dictionaries/edu_zipf.parquet neither the extractor nor the document means are planned and no Edu_Zipf_* / mean_edu_zipf_* column is written, whatever the toggles say. If the extractor is called directly with no lookup file, it still returns the five columns as NaN and logs a warning.
  5. The bands argument lets the caller emit only a subset of columns — the GUI's per-band toggles flow through to this argument so disabled bands are simply not added to the output DataFrame.

Why:

  • Lookup keyed on lowercased lemma — matches the SUBTLEX extractor's convention so the two frequency columns are comparable lexeme-for-lexeme.
  • Parquet over CSV — vectorised pandas lookup is fast and the file format compresses well for a ~5-column-by-N-row table.
  • Gated in the planner, not the GUI — the GUI greys the toggles out, but run.py follows config/features.yaml as written. Before the gate, a config with the toggles on made a headless run write five all-NaN word columns and five all-NaN document columns that a GUI run did not.

6.1.9.7Library

The lookup is a plain pandas-on-pyarrow read:

import pandas as pd
lookup = pd.read_parquet("data/dictionaries/edu_zipf.parquet").set_index("word")
lookup.loc["house"]
# edu_zipf_k2        4.21
# edu_zipf_3to5      4.93
# edu_zipf_6to8      5.18
# edu_zipf_9to12     5.41
# edu_zipf_overall   5.27

6.1.9.8EEG rationale

EWFG is the right reference corpus when the question is age of acquisition, developmental exposure, or literacy-graded difficulty — i.e. when SUBTLEX-US's adult-conversational baseline is the wrong yardstick.

  • A word's Edu_Zipf_K2 measures how often a young child has plausibly encountered it in print. Words with high K2 frequency but low 9to12 frequency (function words, common nouns) behave differently from words with low K2 but high 9to12 frequency (acquired-late vocabulary). The guide's overall frequency does track age of acquisition (AoA): r = −.281 across the 72 target words of Juhasz 2003. But no paper we know of tests the K2-vs-9to12 contrast as an AoA measure, so treat that use as exploratory; for AoA itself, use the rated norms of Kuperman 2012.
  • Age of acquisition independently predicts eye fixation durations in naturalistic reading (Juhasz 2003, Dirix 2017) and N400 amplitude in single-word ERP studies (Yum 2019), with effects that persist after controlling for word frequency. The per-band columns therefore let you regress out a developmental-exposure covariate that pure SUBTLEX cannot capture.
  • Edu_Zipf_Overall is the closest EWFG analogue to general Zipf_Freq and is most useful as a sanity-check baseline against the SUBTLEX value.

6.1.9.9Papers

  • Zeno 1995 Zeno, Ivens, Millard, Duvvuri. The Educator's Word Frequency Guide. Touchstone Applied Science Associates. — the source norms for the per-band frequencies.
  • Kuperman 2012 Kuperman, Stadthagen-Gonzalez, Brysbaert. Age-of-acquisition ratings for 30,000 English words. Behavior Research Methods 44, 978–990. doi:10.3758/s13428-012-0210-4 — large AoA norms; the construct's empirical basis.
  • Juhasz 2003 Juhasz & Rayner. Investigating the effects of a set of intercorrelated variables on eye fixation durations in reading. J. Experimental Psychology: Learning, Memory, and Cognition 29(6), 1312–1318. doi:10.1037/0278-7393.29.6.1312 — AoA effects on eye fixation durations after controlling for frequency, familiarity, length, and concreteness.
  • Dirix 2017 Dirix & Duyck. The first- and second-language age of acquisition effect in first- and second-language book reading. J. Memory and Language 97, 103–120. doi:10.1016/j.jml.2017.07.012 — AoA effects on eye movements during naturalistic book reading (GECO corpus).
  • Yum 2019 Yum & Law. Interactions of age of acquisition and lexical frequency effects with phonological regularity: An ERP study. Psychophysiology 56(10), e13433. doi:10.1111/psyp.13433 — single-trial ERP analysis shows AoA modulates N400 amplitude independently of word frequency.
