Features

6.1Word level

One row per word (and punctuation token) in word/<stim>_features.csv, plus the word-embedding .mat files.

6.1.1Structural

App: Word-level features page → Structural card.

6.1.1 Structural identifier columns
Bookkeeping columns that uniquely locate each word within the document hierarchy.
6.1.2 Structural character offsets
1-indexed, inclusive character offsets of each token within the sentence string (the sentence column).
6.1.3 Sentence text
The verbatim text of the sentence containing each word, including punctuation and original whitespace.

6.1.2Linguistic annotations

App: Word-level features page → Linguistic annotations card.

6.1.4 Tokens and lemmas
The two most basic lexical columns.
6.1.5 Part-of-speech tags
Two grammatical category tags per word, from spaCy's POS tagger.
6.1.6 Morphological features
Per-token morphological feature bundle in Universal Dependencies (UD) FEATS format (Nivre 2016): a pipe-separated list of Attribute=Value pairs describing the token's inflectional properties.
6.1.7 Dependency parse
Per-token syntactic-dependency annotation.

6.1.3Frequency

App: Word-level features page → Frequency card.

6.1.8 Word frequency (Zipf, wordfreq)
Per-word lexical frequency on the Zipf scale, looked up from the wordfreq library's combined English list.
6.1.9 Educator's Word Frequency Guide (EWFG) grade-band frequencies not computed here
Per-word Zipf-scale frequencies derived from the Educator's Word Frequency Guide (Zeno 1995), a corpus of texts that American schoolchildren actually encounter, bucketed by grade band.

6.1.4Predictability

App: Word-level features page → Predictability card.

6.1.10 Surprisal
Per-word surprisal — the negative log probability that a language model assigns to a word given everything that came before it in the document, in bits.
6.1.11 Cloze probability
The conditional probability that a selected model assigns to each word given preceding context — i.e.
6.1.12 Top-1 prediction match
Binary flag (0 or 1) indicating whether a selected model's most likely next word at this position matched the actual word in the transcript.

6.1.5Semantic indicators

App: Word-level features page → Semantic indicators card.

6.1.13 Semantic-domain category indicators
Per-word indicators of membership in semantic / psychological categories from a dictionary backend (LIWC or Empath).

6.1.6Semantic similarity

App: Word-level features page → Semantic similarity card.

6.1.14 Word2Vec static word embeddings
A single 300-dimensional vector per word, looked up from a pretrained static embedding table (Google News 100B-word corpus).
6.1.15 BERT contextual word embeddings
A 768-dimensional vector per word, emitted at every one of BERT's 12 transformer layers.

6.1.7Lexical norms

App: Word-level features page → Lexical norms card.

6.1.16 Lexical norms (AoA, concreteness, imageability, familiarity, VAD)
Per-word psycholinguistic ratings looked up from published norm databases, keyed by lemma (with a surface-token fallback).

6.1.8Acoustic (word timing)

App: Word-level features page → Acoustic (word timing) card.

6.1.17 Acoustic word boundaries (MFA)
The actual acoustic start and end times of each word in the audio, in seconds from audio onset, from forced alignment of the transcript against the audio with Montreal Forced Aligner (MFA).
6.1.18 Acoustic word duration and gap
Two derived timing columns, both in seconds, computed from Onset / End.

6.1.9Prosody

App: Word-level features page → Prosody card.

6.1.19 Word-level pitch features
Five per-word summary statistics of the fundamental frequency (F0) contour, computed within each word's MFA-aligned acoustic window (Onset, End).
6.1.20 Word-level volume (intensity) features
Five per-word summary statistics of the intensity contour (loudness in dB SPL), computed within each word's MFA-aligned acoustic window (Onset, End).
