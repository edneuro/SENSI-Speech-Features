Features

6.3Sub-word level

One row per syllable in syllable/<stim>_syllables.csv and per phoneme in phoneme/<stim>_phonemes.csv, plus phoneme/<stim>_phoneme_surprisal.mat.

6.3.1Syllable timing

App: Sub-word features page → Syllable timing card.

6.3.1 Syllable timing (Onset / End / Duration)
Per-syllable acoustic timing in the &lt;stim&gt;_syllables.csv sidecar.

6.3.2Syllable labels

App: Sub-word features page → Syllable labels card.

6.3.2 Syllable labels (orthographic + ARPABET + IPA)
Three label columns identifying each syllable in syllable/&lt;stim&gt;_syllables.csv.

6.3.3Syllable prosody

App: Sub-word features page → Syllable prosody card.

6.3.3 Syllable-level prosody (pitch + volume + deltas)
Four per-syllable prosody columns in &lt;stim&gt;_syllables.csv, scaled-down analogues of the word-level pitch and volume features.

6.3.4P-center

App: Sub-word features page → P-center card.

6.3.4 Perceptual centre (P-center)
Perceptual onset of each syllable — the time point listeners perceive as the syllable's &quot;beat&quot; — rather than the physical acoustic onset.

6.3.5Phonemes

App: Sub-word features page → Phonemes card.

6.3.5 Phoneme-level columns
One row per phone (phoneme) in phoneme/&lt;stim&gt;_phonemes.csv.
6.3.6 IPA phoneme symbol
One IPA segment per row of phoneme/&lt;stim&gt;_phonemes.csv, giving the same phone as the ARPABET column in the notation most phoneticians and most non-English-speech literature actually read.
6.3.7 Out-of-dictionary words (MFA G2P) not computed here
An alignment option, not a feature column: it changes how MFA handles a word that is missing from its pronunciation dictionary.

6.3.6Phoneme surprisal

App: Sub-word features page → Phoneme surprisal card.
