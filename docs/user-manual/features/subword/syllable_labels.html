6.3.2Syllable labels (orthographic + ARPABET + IPA)

Three label columns identifying each syllable in syllable/<stim>_syllables.csv.

App: Sub-word features → Syllable labelsOutput: syllable/<stim>_syllables.csvLibraries: pyphen, montreal-forced-aligner

6.3.2.1What it is

Three label columns identifying each syllable in syllable/<stim>_syllables.csv:

Column Source Example: below
Label Orthographic, from pyphen hyphenation "be", "low"
ARPABET Phonetic, dash-joined ARPABET phones including stress digits "B-IH0", "L-OW1"
IPA Phonetic, dash-joined IPA segments, no stress marks "b-ɪ", "l-oʊ"

A longer word, showing what happens when pyphen's split does not match the phone-derived syllable count — Adrianna, whose MFA pronunciation is EY2 D R IY0 AE1 N AH0 (four phonological syllables) while pyphen offers only three fragments (Adri-an-na):

syllable_id  Label      ARPABET    IPA
    1        EY         EY2        eɪ
    2        D-R-IY     D-R-IY0    d-ɹ-i
    3        AE         AE1        æ
    4        N-AH       N-AH0      n-ə

Note Label here is not orthographic — the count mismatch triggered the stress-stripped-ARPABET fallback described below.

Label is the printable syllable form for human-readable inspection and downstream joins on orthographic syllables. ARPABET is the phonological form used by stress-aware analyses — the trailing digit 0/1/2 on each vowel encodes the lexical stress (0 = none, 1 = primary, 2 = secondary). IPA is the same phonological form in the notation most phoneticians read; it is a relabelling of ARPABET, not a new measurement, so the two are redundant as regressors.

feat_syllable_ipa is off by default, matching feat_syllable_arpabet's precedent for verbose string columns — enable it on the GUI's Sub-word page if you want it.

⚠️ The two levels encode stress differently. This is deliberate.

Stress lives in… Example
Syllable CSV the ARPABET string itself, as a digit suffix per vowel D-R-IY1
Phoneme CSV a separate Stress column; ARPABET is bare ARPABET=IY, Stress=1

The phoneme CSV carries ARPABET, Stress and IPA as separate columns. The syllable CSV's ARPABET is a dash-joined string over several phones, so there is no single stress value to lift out of it, and stripping the digits would destroy information; the syllable CSV adds only an IPA column.

Consequences to keep in mind:

  • Do not write a stress filter that works on both files. On the syllable CSV you still need a string test; use the phoneme CSV if you want numeric stress.
  • The syllable IPA column carries no stress information at all — no ˈ/ˌ marks (they are not emitted; see feat_phoneme_ipa) and no digits. If you need the syllable's stress alongside its IPA, read it off ARPABET, or join the phoneme CSV on (doc_id, sentence_id, token_in_sentence_id, syllable_id) and take Stress where Stress.notna().
  • There is deliberately no syllable-level Stress column. Adding one was considered and rejected as out of scope for the additive-only change to this file.

6.3.2.5Usage

  • Group / filter by primary-stress syllables — pitch accents on stressed syllables elicit a P200 ERP modulated by the F0-peak onset latency, making stressed syllables the canonical units for prominence-related ERP analyses (Heim 2006).
  • Build syllable-class regressors (e.g. open vs. closed syllables) by parsing the ARPABET string.
  • Match syllables across stimuli by their ARPABET string for stimulus-pair contrasts in phonological-similarity studies. Use IPA instead when matching against a corpus that is not ARPABET-annotated.

6.3.2.6In the code

Open in GitHub
  • sensi/extractors/syllabify.py → assign_labels()
  • sensi/extractors/arpabet_ipa.py → syllable_to_ipa()

Source: sensi/extractors/syllabify.py:assign_labels (Label / ARPABET) and sensi/extractors/arpabet_ipa.py:syllable_to_ipa (IPA), both downstream of MFA alignment.

  • Label is generated by running pyphen.Pyphen("en_US").inserted() on the word's surface form and splitting on the inserted hyphens — but only when pyphen's fragment count matches the phone-derived syllable count for that word. Pyphen hyphenates text with Hunspell hyphenation dictionaries (Pyphen), i.e. it finds places a word may be broken across a line. Hyphenation rules are deliberately stricter than syllable division, avoiding breaks "that might cause the reader to pronounce a word incorrectly" (Liang 1983, ch. 5), so its fragments don't always match phonological syllables; the ARPABET column is the better source when phonological boundaries matter.
  • ARPABET is built by joining all phones in the syllable with -, preserving the stress digit suffix on each vowel phone.
  • IPA is built by mapping each phone through arpabet_ipa.to_ipa and joining with -. It is computed from the same (code, stress) pairs the phoneme rows are built from, in the same loop, so the two CSVs can never disagree about a phone. Unmappable segments are dropped rather than emitted as empty fields, so a syllable containing MFA's unknown-word phone spn yields an empty string rather than a run of stray dashes — an oov_unresolved word's single syllable therefore has a non-empty ARPABET (spn) but an empty IPA.
  • When pyphen is unavailable, or its fragment count doesn't match the phone-derived syllable count, Label falls back to the same dash-joined ARPABET string as the ARPABET column but with stress digits stripped (e.g. "B-EH" instead of "B-EH1") — see the warning in articulation_rate for the same dependency.

Which words reach this file affects row counts on real stimuli:

  • A token that shares one MFA word with the token before it (spaCy's was + n't against MFA's single wasn't) emits its syllable rows once, under the first token.
  • An out-of-dictionary word yields exactly one syllable carrying ARPABET = 'spn'.

Both are described in full in phoneme.

6.3.2.7Papers

  • Heim 2006 — see prosody_pitch — P200 ERP elicited by pitch accents on stressed syllables.

  • The ARPABET inventory and its stress-digit convention, and the ARPABET↔IPA correspondence used by the IPA column, are cited in feat_phoneme_ipa.

  • Pyphen Kozea. Pyphen — pure Python hyphenation using Hunspell hyphenation dictionaries. github.com/Kozea/Pyphen — the dictionaries come from LibreOffice's repository.

  • Liang 1983 Liang. Word Hy-phen-a-tion by Com-put-er. PhD thesis, Stanford University (STAN-CS-83-977). tug.org/docs/liang/liang-thesis.pdf — hyphenation for typesetting: allowable line-break points, not a syllabifier.
