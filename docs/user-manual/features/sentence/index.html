6.4Sentence level

One row per sentence in sentence/<stim>_sentences.csv, plus sentence/<stim>_bert_sentence.mat.

6.4.1Sentence timing

App: Sentence features page → Sentence timing card.

6.4.1 Sentence timing
Per-sentence timing and text in the &lt;stim&gt;_sentences.csv sidecar.

6.4.2Sentence prosody

App: Sentence features page → Sentence prosody card.

6.4.2 Sentence-level pitch features
Five per-sentence summaries of F0 across each sentence's audio window (Onset, End), in the same units as the word-level pitch columns.
6.4.3 Sentence-level volume (intensity) features
Five per-sentence summaries of intensity (dB SPL), in the same units as the word-level volume columns.
6.4.4 Sentence-level Harmonics-to-Noise Ratio (HNR)
Mean Harmonics-to-Noise Ratio, in dB, across all voiced frames inside each sentence's audio window.

6.4.3Sentence embeddings

App: Sentence features page → Sentence embeddings card.

6.4.5 BERT contextual sentence embeddings
A 768-dimensional vector per sentence at each of BERT's 12 transformer layers — the sentence-level analogue of the word-level BERT embedding.
