6.4.3Sentence-level volume (intensity) features

Five per-sentence summaries of intensity (dB SPL), in the same units as the word-level volume columns.

App: Sentence features → Sentence prosodyOutput: sentence/<stim>_sentences.csvLibraries: parselmouth, praat

6.4.3.1What it is

Five per-sentence summaries of intensity (dB SPL), in the same units as the word-level volume columns:

Column Statistic
Volume_Mean Mean intensity inside the sentence's [Onset, End).
Volume_Min 5th-percentile intensity.
Volume_Max 95th-percentile intensity.
Volume_Std Standard deviation of intensity within the sentence.
Volume_Delta Sentence-to-sentence change in Volume_Mean, measured back to the most recent sentence with a value (sentences with no aligned word are skipped). NaN for the first aligned sentence.

6.4.3.4MATLAB

% Load the sentence-level table (one row per sentence)

T.Properties.VariableNames             % every column in the file
head(T(:, {'sentence_id', 'Volume_Mean', 'Volume_Min', 'Volume_Max', 'Volume_Std', 'Volume_Delta'}), 10)                % this feature's columns (first rows)
Run from the output folder. Variable and column names were checked against the real files when this manual was built; the code itself was not run in MATLAB.

6.4.3.5In the code

Open in GitHub
  • sensi/extractors/sentence_prosody.py

Source: sensi/extractors/sentence_prosody.py. Same Praat intensity contour as the word- and document-level extractors; sliced to each sentence's [Onset, End). The aggregation function (_agg(slice) = (mean, p5, p95, std)) is shared with the word-level volume extractor.

6.4.3.6EEG rationale

Sentence-level volume summaries serve the same purposes as sentence-level pitch: stimulus matching and prosody-aware regression covariates. They are partly confounded with sentence-level Pitch_Std and with the sentence's word count — so analyses should include both.

Volume_Delta captures the discourse-level "loudness arc" of a narrative (rising during climaxes, falling during calm sections); useful as a continuous regressor for engagement-modulated EEG/MEG responses.

6.4.3.7Papers

See prosody_volume — sentence-level summaries inherit the same foundational references (Boersma 2018, Zelger 2024, Cole 2019).
