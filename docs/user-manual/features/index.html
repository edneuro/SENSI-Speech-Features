6Features

Every feature SENSI SpeechFeatures produces, grouped the way the app groups them: one chapter per output level (the app’s feature pages), one section per card on that page.

6.1 Word level
One row per word (and punctuation token) in word/<stim>_features.csv, plus the word-embedding .mat files.
20 feature pages
6.2 Document level
One row per stimulus in document/documents_summary_<timestamp>.csv.
11 feature pages
6.3 Sub-word level
One row per syllable in syllable/<stim>_syllables.csv and per phoneme in phoneme/<stim>_phonemes.csv, plus phoneme/<stim>_phoneme_surprisal.mat.
8 feature pages
6.4 Sentence level
One row per sentence in sentence/<stim>_sentences.csv, plus sentence/<stim>_bert_sentence.mat.
5 feature pages
6.5 Acoustic level
Audio-only time series in acoustic/<stim>_acoustic.mat, on one shared time grid set by the analysis rate.
4 feature pages

How to read a feature page

Each feature page has the same parts, listed on the right as you read:

  • What it is — the plain meaning, and the exact column or variable names.
  • See it — a figure drawn from SENSI SpeechFeatures’ real output on a public-domain example (LJ Speech recordings, or short invented texts run without audio). Where a setting changes the result, you can switch between real runs that differ only in that setting.
  • In your output — which file it lands in, and an excerpt of that file.
  • MATLAB — how to load it, inspect it and plot it.
  • How it’s computed, In the code, Library — the method, the function that does it (linked to GitHub) and the libraries used.
  • EEG rationale and Papers — why it matters for EEG, with links to the papers.

Pages marked ◇ in the outline describe features that cannot be computed on the manual’s examples; they explain why instead of showing a figure.

In the app, each level is a page in the sidebar: Word-level features, Document-level features, Sub-word features, Sentence features, Acoustic.
