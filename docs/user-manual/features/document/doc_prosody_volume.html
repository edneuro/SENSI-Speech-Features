6.2.8Document-level volume (intensity) summaries

Five document-level summaries of intensity (dB SPL) across the entire stimulus, in the same units as the word-level volume columns.

App: Document-level features → ProsodyOutput: document/documents_summary_<timestamp>.csvLibraries: parselmouth, praat

6.2.8.1What it is

Five document-level summaries of intensity (dB SPL) across the entire stimulus, in the same units as the word-level volume columns:

Column What it summarizes
doc_volume_mean Mean intensity across the audio.
doc_volume_min 5th-percentile intensity.
doc_volume_max 95th-percentile intensity.
doc_volume_std Standard deviation of intensity.
doc_volume_delta_mean Mean of the absolute word-level Volume_Delta values (rises and falls don't cancel).

The first four operate on the raw intensity contour (all frames), the last on word-to-word deltas (averaged as magnitudes).

6.2.8.4MATLAB

% Load the document-level table (one row per stimulus)
T = readtable('document/documents_summary_<timestamp>.csv', 'TextType', 'string');
T.Properties.VariableNames             % every column in the file
head(T(:, {'stimulus_id', 'doc_volume_mean', 'doc_volume_min', 'doc_volume_max', 'doc_volume_std', 'doc_volume_delta_mean'}), 10)                % this feature's columns (first rows)

% Plot
barh(T.doc_volume_mean); yticks(1:height(T)); yticklabels(T.stimulus_id); xlabel('doc_volume_mean')
Run from the output folder. Variable and column names were checked against the real files when this manual was built; the code itself was not run in MATLAB.

6.2.8.5In the code

See word-level volume features — the document-level columns reuse the same Praat intensity contour, aggregated over the full audio. doc_volume_delta_mean is the NaN-aware mean of the absolute word-level Volume_Delta values (word_df["Volume_Delta"].abs().mean()), so rises and falls don't cancel.

6.2.8.6EEG rationale

  • doc_volume_mean is a gross-level acoustic confound — sound level drives the amplitude of the N100 component of the auditory evoked response in a linear fashion (Zelger 2024), so loudness differences across stimuli will be reflected in early ERPs irrespective of any linguistic contrast. Either equalize loudness during stimulus preparation or include this column as a regression nuisance.
  • doc_volume_std captures dynamic-range variability — useful as a matching covariate when comparing studio-quality vs. in-the-wild recordings.
  • doc_volume_delta_mean is the document-level analogue of the word-level Volume_Delta average (unsigned) — captures how much loudness changes from word to word, a continuous proxy for prosodic expressiveness.
