Features

6.2Document level

One row per stimulus in document/documents_summary_<timestamp>.csv.

6.2.1Counts

App: Document-level features page → Counts card.

6.2.1 Document-level count columns
Four basic size descriptors per document, all integers, in the document-level summary CSV.

6.2.2Aggregates

App: Document-level features page → Aggregates card.

6.2.2 Word-level feature aggregates
Document-level means of word-level lexical features.

6.2.3Lexical diversity

App: Document-level features page → Lexical diversity card.

6.2.3 Lexical diversity (TTR + MTLD)
Two complementary indices of vocabulary richness at the document level.

6.2.4Readability

App: Document-level features page → Readability card.

6.2.4 Readability (Flesch Reading Ease + Flesch–Kincaid Grade Level)
Two classical readability indices computed over the full transcript.

6.2.5Category proportions

App: Document-level features page → Category proportions card.

6.2.5 Document-level category proportions
For each active semantic category (selected on the Word-level features → Semantic indicators card), the document summary CSV gains two columns.

6.2.6Composite psychological scores

App: Document-level features page → Composite psychological scores card.

6.2.6 Composite psychological scores (LIWC-style summary variables)
Four document-level scores that summarize the style of a whole passage from the relative frequencies of different word types.

6.2.7Document prosody

App: Document-level features page → Document prosody card.

6.2.7 Document-level pitch summaries
Five document-level summaries of F0 across the entire stimulus, in the same units as the word-level pitch columns (semitones relative to speaker median by default; Hz if configured).
6.2.8 Document-level volume (intensity) summaries
Five document-level summaries of intensity (dB SPL) across the entire stimulus, in the same units as the word-level volume columns.
6.2.9 Document-level pause statistics
Four document-level summary statistics of silent pauses in the audio.
6.2.10 Articulation rate
Syllables per second of speaking time: the speech span (first word's onset to last word's end) minus the silent pauses longer than the pause threshold.
6.2.11 Document-level Harmonics-to-Noise Ratio (HNR)
Mean Harmonics-to-Noise Ratio, in dB, across all voiced frames in the audio.
