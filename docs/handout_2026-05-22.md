## Key codebase facts needed to execute the plans

### Prefs schema is currently v8
- Active constants: `SCHEMA_VERSION_V8`, `DEFAULT_PREFS_V8`, `_FEATURES_DEFAULT_V8`, `_OUTPUT_DEFAULT_V8`
- File: `utils/preferences.py`
- Migration chain test: `tests/planner/test_schema_drift.py` (imports `_FEATURES_DEFAULT_V8`, `_OUTPUT_DEFAULT_V8` — must be updated to V9 after prefs task)

### Critical: schema drift test
`tests/planner/test_schema_drift.py` enforces that every prefs key is either in a cluster's `toggle_keys` or in an explicit exclusion set. This test WILL fail after adding v9/v10 prefs keys until the planner registry is also updated. The plan handles this in the right order (prefs → registry → test update in a single task).

### `Contours` dataclass is frozen
`extractors/audio_features.py` — must add `hnr_frame_db` and `hnr_frame_times` as **optional fields with default=None** (fields with defaults must come after required fields in a frozen dataclass). Existing tests that construct `Contours` directly will NOT break because the new fields have defaults.

### `_active_clusters` in plan.py needs a 1-line patch
When embedding clusters are added (empty `toggle_keys=()`), the existing guard `if any(...toggle_keys...)` evaluates `any([]) = False` and never activates them. The fix (in `gui/planner/plan.py`) is:
```python
if c.toggle_keys and not any(_toggle_value(prefs, k) for k in c.toggle_keys):
    continue
```

### main.py embedding defaults
Embedding emission in `run_word_level_batch` uses `getattr(args, 'no_word2vec', True)` (default **True** = skip). This prevents existing tests and CLI users without model files from crashing. The GUI's emit.py will set these flags explicitly from prefs.

### Word2Vec model is NOT bundled
~3.6 GB. User must download `GoogleNews-vectors-negative300.bin` manually and place at `hf_cache/word2vec/`. The extractor raises `Word2VecUnavailable` (caught silently in batch) if the file is absent. `download_models.py` has been updated with instructions (in the plan — not yet in code).

### ToggleRow constructor signature
```python
ToggleRow(label: str, parent=None)
```
There is no `initial` / `checked` parameter — use `toggle.set_checked(True)` after construction. The sentence plan incorrectly passes `initial` as a second arg to `ToggleRow`. Fix: call `t = ToggleRow(label); t.set_checked(initial)` instead.

### Card widget API
- `card.add_widget(w)` — adds a QWidget to the card body
- `card.add_layout(lay)` — adds a QLayout to the card body
- **No** `card.layout().addWidget(w)` (that exposes the internal layout) — use the `add_widget` method
