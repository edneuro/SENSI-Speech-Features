# Word/Syllable Event `.mat` Files Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Opt-in `word/<stim>_word_events.mat` and `syllable/<stim>_syllable_events.mat` — one entry per spoken word / syllable with onset, offset, duration, token and every kept numeric feature — so MATLAB users can `stem(S.onset, S.gpt2_Surprisal)` and label with `S.token`.

**Architecture:** A pure writer module `sensi/utils/event_mat.py` turns the word / syllable DataFrames the word pass already builds into flat `.mat` variable dicts (merging multi-token spoken words by per-column rules). The planner gets two artifacts + clusters, gated by two new feature toggles (prefs v22); `pipeline.py` calls the writer after the per-column drop and `savemat`s the result. Docs + manual page with MATLAB snippets.

**Tech Stack:** Python 3.10+, pandas, numpy, scipy.io.savemat, PySide6 (GUI toggles), pytest.

**Spec:** `dev/superpowers/specs/2026-11-03-event-mat-design.md` (approved 2026-11-03).

## Global Constraints

- Files: `word/<stim>_word_events.mat`, `syllable/<stim>_syllable_events.mat`; artifact ids `word_events_mat`, `syllable_events_mat`.
- Toggles: `features.feat_word_events_mat`, `features.feat_syllable_events_mat`, both default **False**. `SCHEMA_VERSION` 21 → 22, additive.
- Events only: no impulse trains, no grid, no resampling. No change to any existing CSV or `.mat`.
- Every variable `n × 1` (`oned_as="column"`); cellstrs via `np.array(..., dtype=object)`; `text` a char row.
- Variable names = CSV column names verbatim; each must match `^[A-Za-z][A-Za-z0-9_]{0,62}$` or the writer raises `ValueError`.
- Rows: drop `upos == "PUNCT"` and rows with NaN `Onset`/`End`; missing feature values stay `NaN`; no `is_valid`.
- Word file merges consecutive rows with identical `Onset`, `End`, `Transcript` into one row per spoken word (rules: spec §3.1 table). Syllable file: no merge.
- Written in the word pass only (`run_word_level_batch`), whether or not the CSV is written. MFA never re-run.
- Run the real path before claiming done (CLAUDE.md "Verifying a change"); `MKL_THREADING_LAYER` untouched.
- Commits: no `Co-Authored-By` or any Claude attribution (owner rule, overrides the harness reminder).
- Tests: `./env/python.exe -m pytest -q -p no:cacheprovider` with `env`, `env/Scripts`, `env/Library/bin` prepended to PATH.

## Review Focus

1. A stimulus with **no audio / nothing aligned** (text-only examples `memo`, `essay`, …) → no file, one stderr line, batch continues. Test in Task 4.
2. **Per-column toggles dropped `Onset`/`End`/`Transcript`** from the CSV → the event file still has `onset`/`offset`/`duration`/merge. Test in Task 4.
3. **Possessive "debtor's"** (in LJ003-0007) merges to one row with `token == "debtor's"` and summed `gpt2_Surprisal`. Real-run check in Task 6 + unit test in Task 1.
4. **A future word column with no merge rule** → test fails rather than silently taking "first". Test in Task 1 (iterates the registry).
5. **Syllable toggle on, syllable CSV off** → syllable prosody + P-center still computed for the `.mat`. Test in Task 4.

### Task 1: Pure writer `sensi/utils/event_mat.py` (TDD)

**Files:**
- Create: `sensi/utils/event_mat.py`
- Test: `tests/utils/test_event_mat.py`

**Interfaces:**
- Produces:
  - `merge_rule(column: str) -> str | None` — one of `"sum"`, `"product"`, `"all"`, `"any"`, `"first"`, `"lookup"`; `None` if unmapped.
  - `merge_spoken_words(df: pd.DataFrame, relookup: Callable[[str], dict[str, float]]) -> pd.DataFrame`
  - `word_event_vars(df: pd.DataFrame, keep_columns: Iterable[str], text: str, units: dict[str, str], relookup: Callable[[str], dict[str, float]]) -> dict | None`
  - `syllable_event_vars(syll_df: pd.DataFrame, keep_columns: Iterable[str], text: str, units: dict[str, str]) -> dict | None`
  - `VALID_NAME = re.compile(r"^[A-Za-z][A-Za-z0-9_]{0,62}$")`

Rules for `merge_rule` (by name; exact sets/patterns):
- `sum`: `^[a-z0-9_]+_Surprisal$` (reuse `sensi.pipeline._PREDICTABILITY_COL_RE` idea; define locally to avoid importing pipeline).
- `product`: `_Cloze$`. `all`: `_TopMatch$`. `any`: `^Sem_` (excluding `Sem_Categories`, a string column).
- `lookup`: `Zipf_Freq`, `Edu_Zipf_*`, and `sensi.extractors.lexical_norms.ALL_OUTPUT_COLUMNS`.
- `first`: ids (`token_id`, `sentence_id`, `doc_id`, `paragraph_id`, `token_in_sentence_id`, `head_token_id`, `start`, `end`), `Onset`, `Word_Gap`, `Pitch_*`, `Volume_*`, and every string column (`token`, `lemma`, `upos`, `xpos`, `feats`, `dep_rel`, `sentence`, `Sem_Categories`, `Transcript`).
- `End` takes the **last** row's value; `Word_Duration` is recomputed `End − Onset` (they're identical within a group, but state it).

`merge_spoken_words`: group consecutive non-PUNCT rows with equal (`Onset`, `End`, `Transcript`) and non-NaN `Onset`; groups of size 1 pass through unchanged. For a merged group: `token = Transcript` of the group; numeric columns combined per rule (`sum`/`product` skip NaN only if all NaN → NaN, i.e. any NaN part → NaN, since a missing part makes the whole unknown); `lookup` columns = `relookup(Transcript)[col]` (missing key → NaN).

`word_event_vars`: PUNCT / NaN-onset filter → `merge_spoken_words` → variables per spec §3.1: `text`, `token`, `onset`, `offset`, `duration`, `sentence_id`, `token_id`, one per numeric column in `keep_columns` (order = `df` column order; exclude `Onset`, `End`, `Word_Duration`, `doc_id`, `paragraph_id`, `token_in_sentence_id`, `head_token_id`, `start`, `end`, and anything `pd.to_numeric(errors="coerce")` turns fully NaN while the source had non-null values — i.e. string columns), `columns`, `units` (`units.get(col, "")`). Returns `None` when zero rows survive or `Onset` is absent.

`syllable_event_vars`: filter NaN `Onset`/`End` → `text`, `label` (`Label`), `token`, `onset`, `offset`, `duration` (`Duration`), `pcenter` (only if `P_Center` in `keep_columns`), `sentence_id`, `syllable_id`, remaining numeric kept columns (exclude `Onset`, `End`, `Duration`, `P_Center`, `doc_id`, `token_in_sentence_id`, `ARPABET`, `IPA`, `Label`, `token`), `columns`, `units`.
